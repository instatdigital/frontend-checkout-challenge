# Stage 11. Финализация

## Цель

Подготовить проект к сдаче: README, проверка запуска, ручной прогон, финальные исправления.

## Шаги

### 11.1. README ✅

- Описать команды фронтенда.
- Описать архитектуру FSD и транспортный слой.
- Описать обработку данных: ошибки, идемпотентность, кеш, суммы.

### 11.2. Проверка запуска ✅

- `npm run build -w @checkout/web` — проходит.
- `npm run typecheck -w @checkout/web` — проходит.
- `npm run dev` поднимает API и фронтенд.
- `npm run smoke` — 5 HTTP сценариев проходят.

Примечание: `npm ci` в сессии, где уже загружен Vite/Rolldown, может падать с `EPERM` на `@rolldown/binding-win32-x64-msvc`, потому что нативный `.node` файл занят процессом. В чистом терминале `npm ci` проходит без проблем.

### 11.3. Ручной прогон

- Пройти основной сценарий: каталог → корзина → чекаут → оплата картой → успех.
- Проверить edge cases:
  - пустая корзина,
  - устаревший quote (QUOTE_EXPIRED),
  - 409 в корзине,
  - declined/cancelled карта и повтор,
  - восстановление платежа после перезагрузки.

### 11.4. Финальные правки

- Проверить README на актуальность.
- Проверить `docs/plan.md` — все этапы отмечены ✅.
- Запустить `npm run format`.
- Убедиться, что lefthook прогоняет build/lint/test/typecheck.

## Критерии готовности

- README содержит команды, архитектуру и описание обработки данных.
- `npm run dev` запускает API и фронтенд.
- `npm run smoke` проходит.
- Ручной прогон основного сценария успешен.
