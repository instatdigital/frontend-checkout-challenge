# Этап 4. Корзина — декомпозиция

## Контекст

Корзина показывает список позиций, позволяет менять количество и удалять.
Пустая корзина — сообщение + ссылка в каталог.

EVALUATION A1: «Товар добавляется в корзину, количество меняется, позиция удаляется; состав и итог совпадают с API».

## 4.1. CartItem + CartPage

- `CartPage.tsx` — загрузка корзины через `useApiQuery`, мутации обновления/удаления, пустое состояние
