# Конвенции проекта

## Верификация

После **каждого** изменения файла — код, конфиг, документация — запускать проверки:

```bash
npm run format:check && npm run build
```

Для web-пакета дополнительно:
```bash
npm run test -w @checkout/web
```

Не ждать напоминания. Не пропускать. Если проверка падает — фиксить до перехода к следующему шагу.

## Размер шага

Шаг = один мой ответ на запрос пользователя (одно сообщение с tool calls).
Лимит: 300 строк изменений на шаг (добавлено + изменено, по `git diff --stat`).
Документация и планы — тоже изменения, тоже в лимите.

Правило:
- Перед реализацией: оценить объём. Если > 300 строк — НЕ реализовывать.
- Вместо реализации: сделать декомпозицию, сохранить в `docs/stage-N.M.md`.
- Каждый пункт декомпозиции — отдельный шаг в следующем ходе.
- После изменений: проверить `git diff --stat`, при превышении — откатить лишнее.

Цель: каждый шаг — осмысленный атомарный коммит ≤ 300 строк.

## DRY и обобщение

Компонент **никогда** не работает с сырым `Response`:
- Не вызывает `fetch()` напрямую
- Не проверяет `response.ok`
- Не парсит `response.json()`
- Не разбирает конверт `{data, meta, links}` / `{error, meta}`

Все API-вызоды — только через транспортный слой. Компонент получает типизированные данные или типизированную ошибку.

## Стили

- CSS Modules + БЭМ с полным именованием: `block__element--modifier`
- Компонент = папка: `components/ProductCard/ProductCard.tsx` + `ProductCard.module.css`
- Глобальный файл — только сброс и CSS-переменные

## Копейки

Все суммы с API — копейки (целые числа). Отображение — рубли. Одна функция форматирования, один проход.

## Идемпотентность

Ключ `Idempotency-Key` генерируется на каждое действие (создание заказа, создание оплаты). Хранится до подтверждения результата. При перезагрузке — восстановление по сохранённому ключу.

## Кеш

TanStack Query. Инвалидация после мутаций. Компонент не дублирует логику кеширования.

## Тесты

Vitest. Покрытие ключевых модулей: транспортный слой, API-хуки, поллинг, сессия. Тесты запускаются на каждом шаге верификации.

## Форматирование

Prettier: `singleQuote: true`, `printWidth: 100`, `trailingComma: "all"`. Из `/.prettierrc.json`.
